# Siva and Miles artwork

`runner-and-miles.png` is the revised illustrated race marker and companion portrait. It was generated with the built-in image-generation tool, using the user-supplied burro-race photo plus two additional identity references. The initial face was rejected by the user; this version revises the face and removes the cap to use the clearer portrait references. The source photos remain outside the repository.

The image has an alpha channel. Its rendered appearance is a stylized illustration; likeness is not a biometric identity assertion. Grafana embeds this local asset as one data URI and uses it in both the course marker and companion card. CSS supplies the bob; SVG translation supplies the recorded-route movement.
